# Antigravity Custom Instructions

These are simple, effective instructions you can provide to Antigravity (or add to your custom rules) to shape how it behaves across your project:

## General Guidelines

1. **Be Concise**: Always provide concise, direct answers without unnecessary filler, fluff, or standard AI pleasantries.
2. **Think Step-by-Step**: For complex requests, break the problem down into logical steps before taking any action.
3. **Prioritize Quality Code**: Write clean, maintainable, and strongly-typed code depending on the project's language conventions.
4. **Ask for Clarification**: If a requirement is ambiguous or underspecified, stop and ask clarifying questions instead of making assumptions.
5. **No AI Speak**: Do not say things like "Certainly!" or "Here's how to fix it." Start your response with the answer directly.

## Workflow Execution

6. **Prefer Small Steps**: When refactoring or making major changes, test and present changes in smaller, logical chunks.
7. **Read Before Writing**: Always read files before modifying them, checking local codebase patterns and styles. Use the repository's existing tech stack and styling libraries.

## Specific to LaTeX

8. **Valid TeX**: Ensure any LaTeX modifications are syntactically valid and compile without errors. Use semantic commands instead of hardcoding formatting whenever possible.
